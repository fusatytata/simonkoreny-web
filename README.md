# simonkoreny.cz

Osobní web Šimona Kořenýho: CV, hra a stránka o tom, jak to vzniklo. Statické HTML bez buildu, hostované na GitHub Pages.

- `/cv/` CV (design Plakát)
- `/hra/` hra Chytej, co se počítá
- `/jak-to-vzniklo/` postup a nástroje
- `/` zatím přesměrovává na `/cv/`

Doména fusatytata.cz přesměrovává do `/hra/` (repo `fusatytata-cz`).
